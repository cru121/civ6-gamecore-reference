# City::Buildings::IsInCity

`bool __thiscall IsInCity(Buildings* this, GreatWorkListIndex index) const`

True if a great work with this index sits in any slot of any building in this city.

## Verified from the decompilation
- Same walk as RemoveGreatWork, returning true on the first slot whose index matches.

## Observed in-game (real save, 2026-10-01)
- On a real save, IsInCity returned true for a work held by a leftover Palace slot entry in a city that no longer has the Palace (a "ghost slot"), while the building-based UI lists did not show it; the trade screen did show it.

## Inferred (not confirmed in-game)
- none

## For modders
- Useful to find which city currently holds a great work. The game-wide owner field is not updated on trades (see SetGreatWorkPlayer), so this is the reliable 'current holder' test.
