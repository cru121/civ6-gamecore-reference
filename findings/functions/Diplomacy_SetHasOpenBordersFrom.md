# Player::Diplomacy::SetHasOpenBordersFrom

`void __thiscall SetHasOpenBordersFrom(Diplomacy* this, PlayerTypes otherPlayer, bool grant)`

Grants (+1) or revokes (-1) open borders from another player. It is a counter, not a flag.

## Verified from the decompilation
- Per-player counter at Diplomacy+0x490 + player*4: new = old +/- 1, clamped at 0. Stored through edit().
- When the counter reaches 0: records the current game turn (game+0xc0) in the per-player array `m_iOpenBordersEndedTurn` (tracked-variable wrapper at Diplomacy+0x590, so the array starts at +0x5a0; name from Linux debug info, see topics/linux-debug-symbols.md), indexed by player*4, calls ExpelFromTerritory, and dispatches an 'ended' signal.
- On the 0 -> 1 transition it dispatches a 'started' signal.

## Inferred (not confirmed in-game)
- Multiple sources (deals, agreements) each add 1, so revoking one does not end open borders while another remains. (Medium.)

## For modders
- Granting twice needs two revokes to end. A wrapper should expose the counter semantics clearly, or offer a 'set to exactly N' variant.
