# Map::Feature::Manager::SetVolcanoActive

`void __thiscall SetVolcanoActive(Manager* this, bool flag)  (twin: SetVolcanoInactive)`

Randomly activates one dormant volcano, if fewer are active than intended. It does not take a target volcano.

## Verified from the decompilation
- Rolls with the label 'Choose Active Volcano Roll' over the difference between the wanted and current active count.
- Scans the volcano list (tracked list at this+0x110) for the Nth eligible entry; the bool restricts eligibility (entry[1] != -1 when true).
- Stores the current game turn (game+0xc0) in the volcano's state field (+0x14), then sends a Reporting event with plot coordinates and visibility (0/1/2 for the local observer) plus a localized notification.

## Inferred (not confirmed in-game)
- The bool most likely limits selection to named / natural-wonder volcanoes. (Low: guessed from the condition.)

## For modders
- A wrapper would mean 'a random volcano wakes up', not 'wake this volcano'. The useful target is the per-volcano state change beneath it.
- Behavior depends on the local observer for visibility and notification, which matters in multiplayer.
