# Game summary (Hall of Fame / statistics) data model

Sources: `Base/Assets/Configuration/Data/Schema/HallofFame.sql` (17 tables) and `HallofFame.xml` (rows), the 38 SQL statements of the exe that touch these tables (`Application::GameSummary::*`, `AppLuaGameSummaryLibrary::l*`), `PushGameData` (0x4c4220). Reference: `docs_proto/docs/exe/gamesummary.md`, data `docs_proto/data/exe_gamesummary.json`.

- Configuration tables: StatisticCategories (8 rows), Statistics (28), Highlights, DataPointAggregateScopes/ScopeQueries/Queries/Updates (83 rules: Sum 46, Last 14, MaxSum 9, Max 8, First 4, Count 2 over MajorPlayers, Games, Rulesets, MajorCityObjects, ReligionObjects), GraphQueries (6) / Graphs (38), ReportQueries (5) / Reports (5) / ReportColumns (21), plus `...RulesetOverrides` tables (per-ruleset overrides).
- Recorded tables in `HallofFame.sqlite` (named in the exe statements): Games, GamePlayers, GameObjects, DataSets, DataSetValues, ObjectDataPointValues, GameDataPointValues, RulesetDataPointValues, ChallengeGames. Queried for names and icons from the game databases: Rulesets, RulesetTypes, RulesetDomainOverrides, RulesetUnSupportedValues, Players, Victories.
- The transfer creates the game, objects, datasets and data point values (`BeginGameTransfer`: CreateGame, CreateObject, CreateGameDataset, CreateObjectDataset, DeclareRuleset, CreatePlayer, GetLastSequence) and `UpdateAggregateDataPoints` recomputes the aggregates.
- `PushGameData` fields (25): GameId, GameMode, GameSpeedType, MapSizeType, StartEraType, StartTurn, TurnCount, Ruleset, LastPlayed, VictoryType, VictorTeamId, DefeatType, DifficultyType, plus player fields (PlayerId, PlayerObjectId, TeamId, LeaderName/Type, CivilizationName/Type, IsHuman, IsLocal, IsMajor, Score).
- Limits: statement columns are not attributed to a table when a statement joins several, so recorded-table column lists are approximate; the schema of the recorded tables is not in a shipped file (the exe creates them from its bootstrap database).
