Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

ForgeUI control types

The Controls.Name:Method() API of the UI toolkit. Signatures come from the strings the exe prints for each method; the owning type of a method is inferred where the same method name exists on several types (from the neighbouring methods in the code, or the unique name), and is shown per page.
