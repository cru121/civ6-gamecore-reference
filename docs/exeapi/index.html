Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Engine Lua tables

These Lua tables are not part of GameCore: the engine executable registers them, so GameCore hooks (Community Extension, Frida on the DLL) never see them. They are what UI scripts call: UI.PlaySound(...), Network.HostGame(...), GameConfiguration.GetValue(...), Locale.Lookup(...), and the control methods on Controls.X:SetHide(...).

The exe has no parameter names and no documentation. What this section shows is recovered three ways, always marked inferred:

  • the method names and the registering code (verified: the name is a string literal in the exe and the wrapper address is known);
  • the argument reads and return pushes of the decompiled wrapper (types, optional or not, number of values returned);
  • how the game's own Lua scripts call it (argument counts, kinds, and an example call; parameter names appear only where a script passes the same variable name in most calls).

ForgeUI control methods are different: the exe prints a C++ signature for most of them (void SetHide( bool )), so those types are exact; they are shown as C++ types converted to Lua types.

How to read a signature. Table.Method(a: string, [b: number]) is called with a dot; Type:Method(...) is called on an object with a colon. [...] marks an optional argument. A trailing ... means a helper in the wrapper reads further arguments that were not recovered; the example calls show what the game passes. -> number is the type pushed back to Lua.

How reliable is it. For the 661 static-table and object methods that the game scripts also call, the argument count recovered from code agrees with the scripts for 80% of methods; the code under-counts for 17% (a helper function hides the read) and over-counts for 3% (an extra optional slot). Where they differ the larger number is shown and the other source is in the evidence list.

ForgeUI control types

46 types with 733 methods (the Controls.Name:Method() API; each type lists the methods registered directly on it; a type may also inherit from ControlBase).

Event objects

The exe creates one event object per Lua event (Events.Name, LuaEvents.Name) and gives each the same seven methods; see Event objects.
