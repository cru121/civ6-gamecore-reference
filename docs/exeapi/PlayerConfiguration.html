Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

PlayerConfiguration

Object type with 53 methods. game scripts call these methods on pPlayerConfig / playerConfig variables obtained from PlayerConfigurations[playerID]; the exe registers a type called PlayerConfigurations. Registering function 0x10f4b0.

Methods are called on a value of this type with a colon (obj:Method(...)).
