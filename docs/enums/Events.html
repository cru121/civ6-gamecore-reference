Events

C++ type: GameCore::Events::EventTypes

Engine event ids used by the reporting and event systems (for example Reporting::Event::Send). Each id is the hash of the event name.

  • 351 of the 352 ids equal the hash of their name (see the hash function page). EMERGENCIES_UPDATED has an id that does not match its own name. [verified; evidence: dwarf — enumerator values compared with the computed hash]
  • 13 events never appear as an immediate constant in any function of the symbol or current build, so they are probably sent through a computed id or are unused. [inferred; evidence: static-analysis — scan of all 32-bit immediates in .text]

These are the engine's event ids. About three quarters of them are also Lua events that scripts can subscribe to; those are on the Lua events page with their parameters. The last column gives the Lua name where one is known.
