PlayerComponentTypes

Lua constant table PlayerComponentTypes. Engine enum: GameCore::Player::ComponentID::Type.

The table name and the Lua key column come from the Civilization VI Modding Companion (ChimpanG, expanded and maintained by WildW). The engine names and values come from the game library's debug info. Every member the Companion lists has the same value in the engine enum, which is how the two were matched.

5 of 93 engine members are listed by the Companion. The others exist in the engine, but we do not know whether Lua exposes them, so use the Lua key column as the safe set.
