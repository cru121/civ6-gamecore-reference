Lua events

Events a script can subscribe to with Events.<Name>.Add(handler). Each handler receives the parameters listed here, in this order.

The list and the parameters come from the Civilization VI Modding Companion (ChimpanG, expanded and maintained by WildW). We matched each one to an engine event id in the game library, so the event exists; the parameters themselves have not been checked against the game library. "none listed" means the Companion lists no parameters, which can also mean it does not document them.

256 of the 352 engine event ids appear here. The rest are in the engine ids list only: the Companion does not list them as Lua events (some may be, under a different spelling).

Notes from real use

What real handlers show about these events, beyond the Companion list. Source: Gedemon's Civilization Overhaul (Gedemon, https://github.com/Gedemon/Civ6-GCO, state of 2021-05-20) unless the evidence column says the vanilla game's own Lua. Timing and ordering remarks are the mod author's comments, not re-tested here. See also event order and patterns from a large mod.

Lua event Note Evidence Status
RemotePlayerTurnBegin Handlers receive playerID, although the Companion lists no parameters. vanilla Lua (DiplomacyRibbon.lua OnTurnBegin(playerID)) and GCO PlayerScript.lua:1363 verified
RemotePlayerTurnEnd Handlers receive playerID, although the Companion lists no parameters. vanilla Lua (DiplomacyRibbon.lua OnTurnEnd(playerID)) and GCO PlayerScript.lua:1376 verified
LocalPlayerTurnEnd GCO's handler reads a playerID; the Companion lists none. Not seen in vanilla handlers (they take no arguments). GCO PlayerScript.lua:1394 inferred
ImprovementActivated There is an eighth argument, activationValue, after activationType; the Companion lists seven. Also, the first two arguments are the plot x, y. vanilla Lua (TutorialUIRoot.lua OnImprovementActivated) and GCO PlotScript.lua:2457 verified
