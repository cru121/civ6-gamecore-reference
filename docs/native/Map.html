Map::Feature::Manager::SetVolcanoActive

Randomly activates one dormant volcano, if fewer are active than intended. It does not take a target volcano.

  • Rolls with the label 'Choose Active Volcano Roll' over the difference between the wanted and current active count. [verified; evidence: static-analysis — decompilation read in Ghidra]
  • Scans the volcano list (tracked list at this+0x110) for the Nth eligible entry; the bool restricts eligibility (entry[1] != -1 when true). [verified; evidence: static-analysis — decompilation read in Ghidra]
  • Stores the current game turn (game+0xc0) in the volcano's state field (+0x14), then sends a Reporting event with plot coordinates and visibility (0/1/2 for the local observer) plus a localized notification. [verified; evidence: static-analysis — decompilation read in Ghidra]
  • The bool most likely limits selection to named / natural-wonder volcanoes. (Low: guessed from the condition.) [inferred; evidence: static-analysis — decompilation read in Ghidra]
  • A wrapper would mean 'a random volcano wakes up', not 'wake this volcano'. The useful target is the per-volcano state change beneath it. [inferred; evidence: static-analysis — decompilation read in Ghidra]
  • Behavior depends on the local observer for visibility and notification, which matters in multiplayer. [inferred; evidence: static-analysis — decompilation read in Ghidra]

Map::Feature::Manager::SetVolcanoInactive

Randomly deactivates one active volcano. Mirror of SetVolcanoActive.

  • Same structure with roll label 'Choose Inactive Volcano Roll'; sets the state field to 0xFFFFFFFF instead of the current turn. [verified; evidence: static-analysis — decompilation read in Ghidra]
  • none [inferred; evidence: static-analysis — decompilation read in Ghidra]
  • See SetVolcanoActive. [inferred; evidence: static-analysis — decompilation read in Ghidra]
