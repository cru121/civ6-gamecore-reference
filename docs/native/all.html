All functions: searchable index

Every function of the symbol build (43803) with its address in both builds, a category and, where the name matches, the real signature from the Linux build. Use it to look up any function by name or address. Mapped means the function was found in the current build (33271 of them, 76%); unmapped functions have no current address, mostly because they were compiler-generated or are template instances whose bytes changed.

Rows with ★ have a detailed entry in the native functions section. Search matches the name, the Lua method name, the signature and the addresses (for example 0x68d7f0).
