Home › Engine events › Exe systems and events

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Exe systems and the events they handle

Each system registers handlers for the events listed. Counts are static registrations found in the exe; a system can also subscribe dynamically (for example the Lua event libraries). The first column is the function that registers the handlers.
