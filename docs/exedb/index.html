Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Database and text access

The engine executable talks to SQLite databases in two roles: it reads rows of the game database (Gameplay, Configuration, Localization) for things it needs itself (fonts, audio, colors, victories, features), and it owns two databases of its own: Mods.sqlite (the mod framework: which mods and files exist, which are enabled) and HallofFame.sqlite (game summary and statistics). This section lists every SQL statement that appears as a literal in the exe (191), grouped by table.

Reading the tables. A table name that is also a table of the game database (Features, Eras, Victories, Colors...) shows which of its columns the exe consumes, so a mod that adds a column there is not seen by the exe, and one that changes an existing column affects the exe side too. Statements built at run time (table names assembled from parts) are not in this list.

Verified: each statement is a string literal in the exe and the function that uses it. Inferred: which database it runs against (decided from the table names and the function).
