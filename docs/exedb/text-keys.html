Home › Database access › Text keys in the exe

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Text keys the exe refers to

55 LOC_ keys appear as literals in the exe. Most name maps and scenarios (LOC_MAP_*, LOC_*_SCENARIO_*) and a few system messages; the engine otherwise gets its texts from the database, so changing these keys in a text file changes what the exe shows for them.
