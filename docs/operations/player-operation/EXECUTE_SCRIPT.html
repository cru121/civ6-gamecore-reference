EXECUTE_SCRIPT
Lua constant PlayerOperations.EXECUTE_SCRIPT
Hash 0xc665ad08
Kind Player operations
Status verified
Handler class ExecuteScript::Start
Registered at symbol 0x5b1f0, current —

Routes a UI request to a gameplay-side GameEvents handler named by the OnStart parameter, so a script action is processed through the normal operation path.

-- UI state
local kParameters = {}
kParameters.OnStart = "MyScriptAction"   -- name of the GameEvents handler to run
kParameters.CityID = cityID
UI.RequestPlayerOperation(Game.GetLocalPlayer(), PlayerOperations.EXECUTE_SCRIPT, kParameters)

-- gameplay state
GameEvents.MyScriptAction.Add(function(playerID, kParameters)
    -- act on kParameters.CityID
end)
  • Civ6-GCO uses this as its multiplayer-safe command channel: the UI sends a parameter table with OnStart set to an event name, the engine then fires GameEvents.(playerID, parameters) on the gameplay side. Nested plain tables were passed successfully. It uses five such events (city action, tribe action, production settings, unit settings, deal action). Whether the parameters are synchronised across clients was not tested here; GCO relies on it.
