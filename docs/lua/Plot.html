"same code as" in the Symbol column means the compiler merged identical functions: those methods share one wrapper and cannot be told apart by address.

Notes (★)

IsNone

Only valid on a 'none' plot instance.

  • Called on an existing plot (Map.GetPlotByIndex(0)) it raises "Instance does not exist"; it cannot be used to test an existing plot. [verified; evidence: runtime — called in the running game (UI Lua state, build 15038592, 2026-10-03, single player) by the live test harness]

SetOwner

Sets the owning player and city of a plot.

  • Civ6-GCO needs two steps for a change of owner to show up in the UI context: SetOwner(-1) first, then SetOwner(owner, city, true). It reports that without clearing first 'the UI context doesn't update'. The recovered signature has two parameters (owner, city); the third argument GCO passes is not accounted for and its meaning is unknown. [inferred; evidence: community-reference — Civ6-GCO Scripts/GCO_PlotScript.lua:404-430, 1447; third-party mod Civ6-GCO (Gedemon, 2021), not a Firaxis script]

See also: WorldBuilderCityManager.SetPlotOwner
