Notes (★)

GetGreatWorkDataFromIndex

Returns the data record for a great work list index.

  • Not bounds-checked. Calling it with an index past the end of the great work list reads beyond the list and crashed the game. [verified; evidence: runtime — crash reproduced while opening a screen that scanned past the list end]

See also: Game.GetGreatWorkPlayer

GetGreatWorkPlayer

Returns the player recorded on a great work record, or -1 for an index outside the list.

  • Bounds-checked: an index past the end of the great work list returns -1. [verified; evidence: runtime — observed in game while testing the archive]
  • The recorded player is written only on creation paths (great person, relic, artifact, hero), never when a work is traded, so it is the creator, not the current holder. The holder is whichever city's Buildings contains the work. [inferred; evidence: static-analysis — SetGreatWorkPlayer is not called from Deal GreatWork Enact or City Transfer]

See also: Game.GetGreatWorkDataFromIndex, player-operation.CHOOSE_ARTIFACT_PLAYER

GetWinningTeam

Returns nothing (not two numbers) while no team has won.

  • In a running game with no winner the call returns no values at all, although two numbers are documented; scripts must handle the empty result. [verified; evidence: runtime — called in the running game (UI Lua state, build 15038592, 2026-10-03, single player) by the live test harness]
