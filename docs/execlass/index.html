Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Engine classes

The C++ classes of the engine executable: who inherits from whom, and the virtual functions of each class in vtable order. The information comes from the run-time type information (RTTI) of the Linux build, which the Windows build does not carry, so this is the only place the class structure of the Windows executable can be read from; the two builds are compiled from the same source, so the structure is expected to match. Windows addresses are given for virtual functions that the function index could map (high or medium confidence).

Standard-library, third-party and platform-shim classes are left out (ICU, OpenSSL, the shader language, the Direct3D compatibility layer). 1207 classes remain, with 11959 virtual slots, 1931 of them mapped to a Windows address.

Verified: class names, base classes, vtable contents (read from the Linux file). Inferred: that the Windows build has the same hierarchy and slot order; for GameCore::EngineUtility this was confirmed on the Windows vtable (46 slots, same order).
