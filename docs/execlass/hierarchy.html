Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Inheritance trees

Classes with at least one subclass, grouped under their root. (n) is the number of virtual slots; a class with several bases appears under each. The UI toolkit tree (ForgeUI) shows which controls share methods: a method registered on a base class is available on its subclasses.
