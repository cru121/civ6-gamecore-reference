Home › Engine executable › Option files reference

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Option files reference

The exe registers 194 options. The game writes them into four text files in AppData/Local/Firaxis Games/Sid Meier's Civilization VI/; each file is read at start-up and the comment line above every key is the description the exe carries. Keys are unique across all files, names are case sensitive, and every option below is in exactly one file. This page is the merged, searchable list.

Value types. integer: whole numbers, booleans are 0/1. string: free text. A blank Default means the exe passes no constant I could read, most often 0; it is not "none". Floating-point options are probably missing from this list: they use a different register convention and were not scanned.

Command line. Integer options can also be set for one launch with -Key value; see command-line switches.

Description. Taken from the exe where its registration call could be read, otherwise from the comment in the option file (marked in the data as options-file). Options with no text have none anywhere.

Status. verified: registered in the exe and present in the file the game writes. Sections can be split between files (for example [Video], [Debug]).

Worth knowing

  • [General] AvailableViews (GraphicsOptions): 0 = strategic view only, 1 = 3D only, 2 = both. World Builder is a strategic-view-only experience in practice.
  • [Debug] (AppOptions) holds the switches behind the debug menu, the FireTuner (EnableTuner), World Builder (EnableWorldBuilder), GameCore event logging (EnableGameCoreEventLog) and terrain logging (EnableTerrainLogging).
  • [Gameplay] and [Interface] (UserOptions) are the in-game Options menu; [Multiplayer] has the Play By Cloud webhook settings (TurnWebHookURL, TurnWebHookFrequency).
