Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Log and error messages

Messages that the engine executable writes to its log files or shows when something goes wrong, as they appear in the code (1654, grouped by the subsystem of the function that uses them). Search for a fragment of a line from a log file to find what produces it. %s, %d and similar are filled in at run time.

Verified: the text is a string literal and the named function references it. Inferred: the log file column (the subsystem normally writes to that log, see files and paths); what condition triggers a message is not analysed here, the function name is the best hint. Third-party library messages (OpenSSL, curl, zlib), the shader language and strings whose function has no name are left out.
