Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Lenses and lens layers

The map lenses (appeal, religion, continent, movement range, ...) are built from layers. A layer is a named group of map decorations (hex colouring, icons, labels, borders) that a UI script switches on and off with the UILens Lua table. A lens is a named combination: it lists the layers that are active and the layers the player may still toggle on top (the permission set). Lenses and layer sets are defined in Lenses.artdef; the exe registers the layer names and the UI scripts select lenses by name. This page collects the names from the three places and how the game's own scripts use them. Verified: the names (exe strings, artdef, script call arguments) and the Lua LensLayers constants. Inferred: the meaning of the "permission" set (from its name and use).

How it fits together. UILens.SetActive("<lens>") switches to a lens from the Lens collection (24 lenses in the base game and DLC artdefs); the lens points to an ActiveLayers set and a PermissionMask set of the LensLayers collection, each a list of layer names from the LayersList collection (68 names; note that the artdef collection called LensLayers holds these sets and is not the Lua table LensLayers, which only holds numeric constants). Scripts get a layer's id with UILens.CreateLensLayerHash("<layer>") (110 calls in the game scripts) and toggle it with ToggleLayerOn/ToggleLayerOff; the numeric LensLayers.<NAME> constants of the enum tables number the same layers. See the UILens table for the functions and the ArtDef vocabulary for the artdef parameters.

Differences between the sources. The exe registers 56 layer names (LensManager constructor, 0x197000); the artdef layer list has 68 names (base game and DLC). Names only in the artdef: City_Details, Empire_Details, MapLabels_Deserts, MapLabels_Lakes, MapLabels_MountainRanges, MapLabels_NationalParks, MapLabels_NaturalWonders, MapLabels_Oceans, MapLabels_Rivers, MapLabels_Seas, MapLabels_Volcanoes, Power_Lens, Purchase_Plot. Name only in the exe: WorldCursor. Layer names that scripts hash but neither list contains: SupplyDrops. Lenses never selected by a literal name in the game scripts (they may be selected through a variable): MovementFOW, MovementGood, MovementQueue, TradeRoutes.
