Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

UI XML vocabulary (ForgeUI)

The XML files that define the game's user interface are read by the exe's UI toolkit, ForgeUI. Each control type has code that reads its attributes and child names; this page lists them straight from that code, so it shows every attribute a control type understands, including ones the game's own files never use. The shipped column counts how often the attribute appears on that element in the 346 UI XML files that come with the game.

Of the 338 names found in the exe, 172 are used in shipped files (the rest are supported but not used by the game, or are child element and style names). Verified: the name is a literal in the control's XML-reading code and the shipped counts. Inferred: the element name of each control type (checked against the tags in the shipped files) and the short explanations.

Most control types inherit the attributes of ControlBase (the Container element: Anchor, Size, Offset, Hidden, mouse handling, ...); each type section below lists the names its own code reads in addition and marks those that are also in the base list.
