Home › Engine executable › Multiplayer and lobby vocabulary

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Multiplayer, lobby and Firaxis Live vocabulary

The names the engine executable uses for multiplayer lobbies, connections and the Firaxis Live service (145 names). Most useful for modders: the Lua game list entry (what Matchmaking.GetGameListEntry returns) and the lobby metadata keys behind it, each with its integer or string type read from the decompiled code. The network Lua functions themselves are on the Network and Matchmaking pages; the numeric enums (ServerType, KickReason, NetworkResult, ...) are on the enum tables. Log and error texts are on the messages page.

Scope and omissions. Only names and types are listed. The functions that create the Epic platform and start the Firaxis Live client also contain embedded service identifiers; they were deliberately not read for this page and none of those values are reproduced anywhere in this reference. Nothing here describes what is sent over the network beyond the key names.
