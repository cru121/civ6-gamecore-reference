Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Lua enum tables of the exe

Besides the GameCore enums (database types, operations, events), the engine executable registers its own global Lua tables of named numbers: 74 tables with 640 members. They are what Keys.VK_..., MouseEvents.LButtonDown, ServerType.SERVER_TYPE_STEAM or InterfaceModeTypes.SELECTION mean in the game's UI scripts. The member names and the numeric values were read from the exe's registration code (Verified: each value is a constant stored by the code). For the 10 tables that also exist as GameCore enums every shared member has the same value in both places. "Script uses" counts how often the game's own Lua files write Table.MEMBER.

Value kinds. small numbers are plain sequence numbers or flags. hash values are 32-bit signed numbers computed from the member names (the same hash as GameCore types, so they are not stable to guess, always use the table in Lua). Values that look like hashes are shown signed, as Lua sees them.
