Home › Engine executable › Imports and dependencies

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Imports and dependencies

The Windows executable is not a single block: it loads game libraries that sit next to it (Base/Binaries/Win64Steam), two platform SDKs (Steam and Epic) and the usual Windows and C runtime DLLs. This page lists every DLL the executable imports and, for each function, how many functions of the exe call it. Read from the import table of CivilizationVI.exe (DX11, July 2024); the role of each DLL is inferred from its name and the functions imported.

Why it matters for modding. The Lua virtual machine (HavokScript_FinalRelease.dll), the database layer (DatabaseDLL_FinalRelease.dll) and the text system (Localization_FinalRelease.dll) are separate DLLs, so a hook on a Lua or database call can be placed in that DLL as well as in the exe. The exe imports only 4 functions from the database DLL: Initialize, Shutdown, CreateConnection, SetDefaultLogger.
