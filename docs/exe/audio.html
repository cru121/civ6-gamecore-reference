Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Audio vocabulary

The names the engine executable passes to its audio system (Wwise): sound events, state and switch values, volume parameters, music playlists and the files that list sound banks. They are string literals referenced by the audio functions (209 names in 39 functions). Where a name is an event, a bank loaded by a mod needs an event with the same name for the game to play it; this page lists what the exe asks for, not what the game's own banks contain. Verified: the name and the function. Inferred: the explanations, from the function names.

See also the volume options and UI.PlaySound, which takes an event name directly from Lua.
