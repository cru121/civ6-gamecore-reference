Home › Engine executable › Files and paths

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Files, folders and paths in the engine executable

Every file name, folder and path that the code of CivilizationVI.exe refers to as a literal string, with the function that uses it. This tells you what the engine reads and writes: which log files it creates, which option and data files it loads, where it looks for mods and maps, and which database files it opens. It does not show names the engine builds at run time (for example %s.log), and files that GameCore (the rules library) writes are not here, such as the AI_*.csv and Game_*.csv logs.

Paths starting with ../../../ are relative to the game's binary folder; Base/ is the base game folder and DLC/ holds the expansions. All entries are verified string literals; what each file is for is inferred from the name and the function that uses it.
