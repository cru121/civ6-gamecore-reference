Home › Engine executable › Debug console

Engine executable. Settings and tools of the game program (CivilizationVI.exe), usable without a mod. Mostly undocumented debug and configuration functionality; descriptions come from analysis of the executable and have not all been tried in the running game.

Debug console

Commands typed into the in-game debug console (the UIE_DebugConsoleInput event). Each handler of the event matches its own commands; help all prints the combined list. The console is only reachable when the debug UI is enabled (see EnableDebugMenu in the option files); not tried in the running game.
