Engine executable functions

A searchable index of the engine executable CivilizationVI.exe (DX11, July 2024 build). The Windows build has no symbols and no class information, so function names come from the Linux build of the same engine, which exports about 199,000 names; a Windows address is listed where the same function could be found there. 1565 functions exist only on Windows (no Linux symbol): the exports named by the PE export table (ForgeUI, Havok), and Lua wrappers and control thunks named by the registration code, WorldView event handlers, the engine utility vtable and the debug console handlers; their Linux address is blank.

  • Search all 50641 functions: by name, Lua method, note, or by address (a Windows RVA such as 0x547000, or a Linux address).
  • Category pages below list the functions that have a Windows address.

What the addresses mean

Windows addresses are RVAs (add the image base 0x140000000 for the address Ghidra shows). Linux addresses are virtual addresses in the Linux Civ6 executable. The DX12 executable has different RVAs and is not covered. Of the 52,101 functions the Windows executable contains, 7566 are named here; the rest have no Linux counterpart or could not be matched. The compiler merges identical functions on Windows, so several Linux names can share one Windows address.

The measured accuracy per method is in the analysis notes (findings/topics/exe-analysis-tooling.md). Names come from the Linux build and can differ in spelling from the Windows build (template arguments, calling conventions).
