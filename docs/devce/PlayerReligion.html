SetSpreadModifier

Arguments: iSpreadMultiplier — base spread multiplier; eSpreadEnhancingTech — tech that upgrades spread; iTechEnabledSpreadMultiplier — multiplier once the tech is researched

Writes - auto-variable at this+0x238 (spread multiplier) - auto-variable at this+0x250 (enhancing tech) - auto-variable at this+0x268 (tech-enabled multiplier)

Side effects - auto-variable assigns likely mark state dirty

Input checks: None: values are stored unchecked, including an invalid tech type.

Preconditions - gameplay Lua state only - must run on the game thread

Multiplayer: may-desync: direct state write. Risk: low (plain stores, no range check but values only consumed by spread math). Confidence of the reading: medium.

Verified from the code - writes three separate auto-variables at 0x238, 0x250, 0x268 with the three parameters unchanged

Inferred - names come from the Linux debug info, so roles are reliable but consumer code was not read
