AddBuildingReplacementOverride

Arguments: eBuildingToReplace — building type that is to be replaced; eBuildingOverride — building type that replaces it

Writes - building replacement override list at 0x168 - cities' buildings (ReplaceBuilding) - can-ever-construct state

Side effects - notifies Rules::Cities OnCityBuildingOverrideAdded and relocates great works in each affected city

Input checks: Ignores -1 for either argument and skips duplicate pairs; does not check the buildings exist.

Multiplayer: may-desync, changes cities' buildings. Risk: high (rewrites buildings in all cities of the player). Confidence of the reading: medium.

ChangeExtraStartingPopulationOffHomeContinent

Side effects - none visible beyond the tracked variable assignment

Input checks: Zero change returns immediately. No range clamp on result.

Input checks: null definition pointers skipped; recomputation only in the branch where civ or leader definition exists

Preconditions - owning player set (this+0x90) - definitions loaded

Multiplayer: safe-deterministic. Risk: medium (bulk rebuild of a cached table; output C is truncated so details unconfirmed). Confidence of the reading: low.
