Details

ClearTempRoutes

Writes - Temporary route vector end pointer

Input checks: None.

Multiplayer: may-desync, clears manager route list. Risk: low (Temp routes are normally local previews.). Confidence of the reading: medium.

DisableDomesticRoutesForPlayer

Arguments: disablePlayer — Player whose domestic routes are removed

Writes - Trade graph routes - Route state via CleanupRemovedRoute

Side effects - Cleanup of removed routes (reason code 7)

Input checks: Checks player ID < 0x41 and that the player exists; otherwise no-op.

Multiplayer: may-desync, removes trade routes. Risk: high (Cancels existing routes.). Confidence of the reading: medium.

DisableInternationalMajorsRoutesForPlayer

Arguments: disablePlayer — Player whose routes with majors are removed

Writes - Trade graph routes - Route state via CleanupRemovedRoute

Side effects - Cleanup of removed routes (reason code 7)

Input checks: Checks player ID < 0x41 and existing; skips itself and null/non-major players.

Multiplayer: may-desync, removes trade routes. Risk: high (Cancels existing routes.). Confidence of the reading: medium.

DisableInternationalMinorsRoutesForPlayer

Arguments: disablePlayer — Player whose routes with minors are removed

Writes - Trade graph routes - Route state via CleanupRemovedRoute

Side effects - Cleanup of removed routes (reason code 7)

Input checks: Checks player ID < 0x41 and existing; skips itself and major players.

Multiplayer: may-desync, removes trade routes. Risk: high (Cancels existing routes.). Confidence of the reading: medium.

DoTurn

Writes - Temporary route vector (via ClearTempRoutes)

Side effects - Dispatches game signal at game+0x280 +0x13b0 when routes were cleared

Input checks: None.

Multiplayer: may-desync, per-turn manager processing. Risk: low (Small turn hook.). Confidence of the reading: medium.

GetEarliestEndTurnForRoute

Arguments: startTurn — Turn the route starts

Input checks: None.

Multiplayer: read-only, computes from rules and era. Risk: low (Pure getter.). Confidence of the reading: medium.

HasActiveRoute

Arguments: plotIndex — Plot index to search for on active routes

Input checks: None.

Multiplayer: read-only, scans edge table. Risk: low (Pure check.). Confidence of the reading: medium.

IsLandRouteAllowed

Arguments: originPlayer — Player whose route would use the plot; iX — Plot X; iY — Plot Y

Input checks: Null plot and -1 player return false; coordinates not range checked beyond map lookup.

Multiplayer: read-only, inspects map and player counters. Risk: low (Pure check.). Confidence of the reading: medium.

IsWaterRouteAllowed

Arguments: originPlayer — Player to check

Input checks: No player validity check; missing trader type passes -1.

Multiplayer: read-only, checks embark ability. Risk: low (Pure check.). Confidence of the reading: medium.

RemoveEdgeByID

Arguments: iID — Edge ID to remove

Writes - Edge hash table, adjacency maps (+0xf0, +0x118), edge free list and count

Input checks: Returns false if the ID is not found.

Multiplayer: may-desync, mutates trade graph. Risk: high (Private graph edit; stale routes may reference it.). Confidence of the reading: medium.
