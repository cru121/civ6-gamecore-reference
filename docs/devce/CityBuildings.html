RemoveAllBuildings

Writes - building plot-location array at this+0x8 set to -1 - building flag array at this+0x20 cleared to 0 - array at this+0x38 set to -1 - wonder type on the wonder plot via the improvement builder

Side effects - dispatches a game signal (+0x210) per removed building - calls RemoveGreatWorkSlots - if the building is a nuclear reactor type, calls Fallout::Manager::RemoveNuclearReactor - calls a virtual on Rules::Cities (slot 0xa8) with the building index and plot - sends Reporting::Event 0xe074eef4 per building with plot coordinates

Input checks: No arguments. Index bounds are checked for the definition arrays; null definition pointers are handled in places but one lookup dereferences without a null check.

Preconditions - gameplay state - city must be fully initialised

Multiplayer: may-desync: mass state mutation including map and wonder state. Risk: high (Wipes all buildings, wonders and side data in one call). Confidence of the reading: medium.

Verified from the code - iterates all slots of the building array - skips slots whose value is -1 - sets slot value to -1 after processing - sends one event per removed building

Inferred - the array at +0x8 maps building type to plot id - flag 0x10 at definition+0x159 means wonder - government lookup with bit 8 means nuclear reactor (odd naming)

Open questions - what the Rules::Cities virtual at 0xa8 does - exact role of the government-collection lookup
