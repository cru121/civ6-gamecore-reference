Input checks: None. The building index is used unchecked to index the array, so an invalid or negative index writes out of bounds (crash or memory corruption risk).

Preconditions - valid building type index - game running (Eras singleton exists) - game thread

Multiplayer: safe-deterministic. Risk: medium (Unchecked array index; otherwise a trivial deterministic write.). Confidence of the reading: high.
