ChangeSightRange

Arguments: iRangeDelta — change to sight range

Observed in the game: Not undone by a -1 call: increasing the sight range reveals map tiles immediately, and if a revealed tile belongs to a city-state the game meets it at once (user-observed: a scientific city-state was met, which gives a free envoy and raised the science yield 3.5 -> 4.5 and shortened the research turns left 7 -> 6). The meeting and the revealed tiles stay when the range is lowered again.

Writes - sight range int in game variable at this+0x858

Side effects - calls Sight::Manager::UpdateMap for the unit's plot when it has a valid position, updating visibility

Input checks: Ignores zero delta and any result that would be negative; position check (> -9999) decides whether to refresh sight.

Preconditions - gameplay state

Multiplayer: may-desync: visibility updates should be identical on all clients. Risk: low (guarded against negative range). Confidence of the reading: high.

Verified from the code - returns early if delta == 0 or new range < 0 - stores new range via edit() on this+0x858 - calls Sight::Manager::UpdateMap(this, plot, true) only when both coords > -9999

Inferred - -9999 coords mean off-map
