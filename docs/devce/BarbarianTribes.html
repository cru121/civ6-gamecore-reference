DoTurnActivate

Arguments: bFirstActivation — Gate flag; function returns immediately when false

Writes - Converts a tribe to a minor civ via ConvertTribeToMinorCiv - Unique-unit claim counter at this+0x100 incremented or reset - Tribe vector opened for edit

Side effects - Random roll (GetRandNum) for tribe choice - LogStats call - May let a tribe claim a unique unit

Input checks: Checks capability 0x6e293fcc and bFirstActivation; null-checks tribe; no other range checks.

Multiplayer: may-desync, converts tribes and uses game RNG. Risk: high (Changes tribe and minor civ state and consumes RNG). Confidence of the reading: medium.
