Side effects - editing the variant map marks the game state changed

ChangeFreeResourcesExtracted

Writes - int array element at this+0x2d0 indexed by resource definition index

Side effects - none beyond the array edit

Input checks: returns silently for resource -1; if the definition is not found the index becomes -1 (0xffffffff) and the write goes to an out-of-range element (crash/corruption risk)

Preconditions - valid resource id - gameplay thread

Multiplayer: safe-deterministic. Risk: medium (unchecked fallback index on unknown resource). Confidence of the reading: high.
