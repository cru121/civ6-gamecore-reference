Details

RemoveExpiredItems

Writes - deal item list (this+0x10..0x18) via Deal::Instance::RemoveItem

Side effects - writes lines to the deal log file - dispatches a three-argument signal (player, player, item) on a Game signal object, once per call - removes items (which may have its own side effects)

Input checks: Null log file is tolerated. Iteration continues using the iterator returned by RemoveItem.

Preconditions - game thread - deal manager initialised

Multiplayer: safe-deterministic. Risk: medium (Removes deal items and fires a signal; private method, depends on deal state.). Confidence of the reading: medium.

Verified from the code - Calls a virtual method at vtable+0x80 on each item to decide expiry - Logs 'Removing expired Deal Items' header once and each item description - Checks IsAtWar between the item's two players; if at war and not yet signalled, determines which side started it and dispatches the signal - Calls RemoveItem for expired items

Inferred - Signal likely indicates a war ending or peace deal expiring; exact signal name unknown - Virtual at +0x80 is IsExpired
